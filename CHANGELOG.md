# Changelog

## 0.2.1

- **Исправлено: Agent и Plan не видели ключ из мастера первого запуска.** Ключи, сохранённые в мастере или на странице Keys, теперь доходят до исполнителя задач и до фонового планировщика без перезапуска.
- **Исправлено: шаги плана не получали результаты предыдущих шагов.** Шаг видит запрос, контракт задачи, последние сообщения диалога и результаты шагов из `depends_on`; чтение несуществующего файла стало ошибкой шага.
- **Работа с одним ключом.** Сжатие контекста и подсказки больше не требуют ключа Gemini; зрение (`vision_analyze`) работает через DeepSeek Flash, если есть только ключ DeepSeek.
- **Логи.** Сбой задачи виден в чате с причиной и замечаниями аудитора; на странице Logs кнопка очистки, вкладки по компонентам, строки на каждый вызов инструмента, смену статуса задачи и вердикт аудита. Токены и ключи маскируются в `backend.log`.
- **Безопасность.** `vision_analyze` читает изображения только внутри песочницы и не блокирует цикл событий. Обновлены `fastapi`, `starlette`, `python-multipart` и npm-зависимости (`pip-audit` и `npm audit` без находок).
- Версия бэкенда в API приведена к версии приложения.
- **Мастер первого запуска.** Подписи кнопок на шагах с ключом и моделью больше не накладываются друг на друга: кнопки не сжимаются и не переносят текст, нижняя строка переносится целиком.
- **Уточняющие вопросы.** Приветствия, благодарности и «ок» («hi.», «привет, как дела?») больше не вызывают пять вопросов; любая просьба по-прежнему проходит через уточнение. Язык вопросов, вариантов и сообщения следует за языком запроса (русский, украинский, английский).
- **Карточка уточнений переживает перезагрузку.** Открытые вопросы приходят вместе с состоянием запуска (`GET /sessions/{id}/run`), окно после перезагрузки загружает состояние запуска первой сессии и показывает карточку снова; опрос идущей задачи тоже возобновляется.
- **Исследование кода.** Новый инструмент `file_grep`: поиск текста или regex по содержимому файлов, ответ `путь:строка: фрагмент`; `.git`, `build`, `node_modules` и бинарные файлы пропускаются. `file_read` читает диапазон строк (`start_line`/`end_line`) с номерами строк и сообщает об обрезке; `file_search` пропускает служебные папки и возвращает стабильно отсортированный список. Папка проекта (`agent_project_root`) доступна агенту только для чтения (`scope="project"`): запись и команды работают только в песочнице.
- **Clean test data** показывает, что будет удалено, спрашивает подтверждение и делает копию базы перед удалением. Ожидание блокировки SQLite увеличено до 10 с.

## 0.2.0: первый публичный релиз

Что входит в релиз (подробный обзор и ограничения: [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md)).

- **Агент.** Три режима: Chat (без инструментов), Agent (цикл с инструментами и подтверждениями), Plan (уточняющие вопросы, формализованное ТЗ, план-граф, параллельное исполнение, аудит по критериям приёмки). Команда агентов: оркестратор и роли с делегированием.
- **Инструменты.** Около двух десятков: файлы, оболочка (default-deny и песочница), веб-поиск и загрузка страниц с защитой от SSRF, Obsidian-совместимые заметки, память (SQLite FTS5), навыки, зрение.
- **Провайдеры.** OpenAI-совместимые API (Gemini, Groq, DeepSeek и др.), пулы ключей, автоподбор цепочек моделей, переход на запасные модели при 5xx, 429, 402, 403, 404 и пустом ответе, бюджетный шлюз, сжатие контекста.
- **MCP и плагины.** MCP-клиент (stdio и streamable HTTP, OAuth 2.1, default-deny, Approve для пишущих инструментов), встроенный каталог, импорт Agent Plugins с отключёнными серверами.
- **Хуки и чекпоинты.** События `pre_tool`, `post_tool` и др., снимок файла перед записью с откатом из интерфейса.
- **Безопасность.** Токен на всех маршрутах API и на WebSocket, проверка заголовка Host, окружение оболочки по allowlist, поиск файлов не выходит за корень песочницы, шифрование данных DLP на диске с проверкой целостности (encrypt-then-MAC).
- **Приложение.** Tauri + React, 16 языков интерфейса, темы, экран первого запуска, расписание задач (cron), профили, экспорт сессий, резервные копии.
- **Сборка и проверки.** Воспроизводимая сборка установщика (PyInstaller + Tauri NSIS), оркестратор `rebuild_and_smoke.py`, 1433 теста бэкенда, сканер секретов в релизной сборке.
